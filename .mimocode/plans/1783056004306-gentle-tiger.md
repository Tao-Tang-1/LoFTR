## LoFTR 输出格式

LoFTR 的 `forward()` 方法**不返回值**，而是直接修改输入 dict：

| 键名 | 形状 | 说明 |
|------|------|------|
| `mkpts0_f` | `[M, 2]` | 图像0的精细匹配点 (像素坐标, [x,y]) |
| `mkpts1_f` | `[M, 2]` | 图像1的精细匹配点 (像素坐标, [x,y]) |
| `mconf` | `[M]` | 每个匹配的置信度分数 |
| `mkpts0_c` | `[M, 2]` | 粗糙匹配点 |
| `mkpts1_c` | `[M, 2]` | 粗糙匹配点 |
| `conf_matrix` | `[N, L, S]` | 完整置信度矩阵 |

**注意**：LoFTR **不计算单应矩阵**，需要用 `cv2.findHomography()` 自己计算。

## 脚本计划

### 文件：`scripts/run_loftr_autox.py`

**功能**：
1. 加载 LoFTR 模型（支持两种方式）
2. 读取 AutoX 所有图像（按文件名排序）
3. 对**相邻图像对**运行 LoFTR
4. 保存完整结果到 JSON

**输出内容**：
```json
{
  "images": ["img1.jpg", "img2.jpg", ...],
  "num_images": 100,
  "matches": [
    {
      "pair": ["img1.jpg", "img2.jpg"],
      "num_matches": 1234,
      "keypoints0": [[x1,y1], [x2,y2], ...],
      "keypoints1": [[x1,y1], [x2,y2], ...],
      "confidence": [0.95, 0.87, ...],
      "homography": [[...], [...], [...]],
      "num_inliers": 800,
      "inlier_mask": [1, 0, 1, ...]
    },
    ...
  ]
}
```

**命令行参数**：
- `--images_dir`: 图像目录（默认 AutoX/images）
- `--weights`: LoFTR 权重路径（可选）
- `--output_dir`: 输出目录
- `--device`: cuda/cpu
- `--resize`: 输入图像缩放
- `--top_k`: 最大保留匹配数
- `--conf_thr`: 置信度阈值

### 两种模型加载方式

**方式1：使用本地权重**（需要下载 outdoor_ds.ckpt）
```python
from src.loftr import LoFTR, default_cfg
matcher = LoFTR(config=default_cfg)
matcher.load_state_dict(torch.load("weights/outdoor_ds.ckpt")['state_dict'])
```

**方式2：使用 kornia**（推荐，无需下载）
```python
from kornia.feature import LoFTR
matcher = LoFTR(pretrained='outdoor')
```

## 验证方法

运行脚本后检查：
1. 输出 JSON 文件是否包含所有 99 个图像对的结果
2. 平均匹配数是否合理（预期数百到数千）
3. 置信度分布是否正常（0-1之间）
4. 单应矩阵是否可计算（需要 >=4 个匹配点）
